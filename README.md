# 《lszjy学生手册》模拟测试题库助手

## 交付物

- **`ks_userscript.user.js`** — 油猴（Tampermonkey）脚本 v2.3.0

## 功能

1. **自动作答（模拟测试）**：模拟测试答题页加载后，题库内(`qid` 命中)的题目自动填入题库答案；
   题库外或答案与选项不匹配的题目自动随机作答（单选/判断随机一项，多选随机非空子集）。
2. **交卷后学习**：交卷后自动跳转成绩页 → 自动打开「本次试卷标准答案」解析页，
   解析每题 `标准答案`，**不在题库的加入题库，与题库不一致的自动修正**。
3. **迭代收敛**：自动循环「开始模拟 → 作答 → 交卷 → 看解析 → 入库 → 下一轮」，
   直到 **连续 3 轮 100 分 且 无新增题、无修正** 才自动停止（另有 200 轮保险上限）。
4. **答题页显示答案**：答题页每道题干旁标注绿色徽章「题库答案：X」（未命中显示灰色
   「题库暂无→随机」），并绿色加亮正确选项。
5. **悬浮控制面板**：右上角显示运行状态、题库量、轮数、连续达标进度、最近一轮成绩；
   提供 开始迭代 / 停止 / 导出题库(JSON) / 导入题库 / 清空题库 / 收起面板。

## 安装

1. Edge 安装 Tampermonkey 扩展（开发者模式允许用户脚本）。
2. Tampermonkey 管理面板 → 新建脚本 → 粘贴 `ks_userscript.user.js` 全部内容 → 保存。
3. 打开 `https://yx.lszjy.com/my/ks.aspx`，点右上角面板「开始迭代」即可全自动跑；
   不点开始则为被动模式：仅在模拟测试答题页显示答案徽章，不自动提交。
